# 정직함 규약

모든 수치·행위 주장에는 **주장 근거 라벨**이 붙습니다. 라벨은 실제로 측정한 결과, 오프라인에서
계산한 값, 벤더 문서에서 가져온 사실을 구분합니다. 이 페이지에는 프로젝트가 주장하지 않는
내용도 적습니다.

## 모델링 대 측정 경계

| 구분 | 이 저장소에서 | 라벨 |
| --- | --- | --- |
| 오프라인 before/after | 합성 데이터에 대한 투영 | `measured = false` |
| 대표 태스크/절감률 | 합성 데이터에 대한 투영 | `measured = false` |
| 실측 실험 09·10·11·12·13 (커밋됨) | 실제 Foundry 호출 · `evidence_tier = directional` (11은 사전등록 게이트 둘을 넘지 못해 VOID, 13은 한 arm이 cost-incomplete) | `measured = true` |
| 여러분 테넌트의 라이브 eval | 실제 측정 (범위: 측정한 워크로드) | `measured = true` |

오프라인 `hero`와 투영 번들은 합성 데이터를 씁니다(`measured = false`). 여기서 나온 숫자는
측정된 절감이 아닙니다.

실험 09·10·11·12·13은 실제 Azure Foundry 호출을 사용한 `measured = true` 결과입니다. 다섯
실험 모두 근거 수준은 `evidence_tier = directional`입니다 — 실험 09·10은 큐레이션 과제 5건,
실험 11·12·13은 24과제 × 4arm × n=3 = 288 계획 셀이며, 모두 **단일 테넌트·1회 측정**입니다.
그 측정에서 무슨 일이 있었는지는 보여 주지만 모든 워크로드에 같은 결과가 난다는 뜻은
아닙니다.

실험 11도 `measured = true`이지만 사전등록에서 고정한 게이트 **둘**을 모두 넘지 못했습니다 —
quality arm의 채점 커버리지가 79.2%로 하한 90%를 밑돌았고, unpriced 43.4%로 cost·balanced
arm이 cost-incomplete가 됐습니다. 두 게이트는 서로 독립이며 어느 하나만으로도 무효입니다.
그래서 결과는 **무효(VOID)**입니다. 측정 기록은 실측 트랙에 남지만 계획했던 비교의
근거로는 쓸 수 없습니다.

[실험 13](lab-notebook/13-router-modes-rate-card-gap.md)은 게이트를 전부 통과했지만, 한 arm의
12개 호출을 요율 카드에 행이 없는 모델이 처리했습니다. 그 셀들은 추정 요율로 채워 넣는 대신
fail-closed로 금액을 보류했고, 그래서 그 arm은 **cost-incomplete**입니다: 합계는 라벨과 함께
보고하되 절감 주장은 싣지 않습니다. 나중에 카드를 정정할 때도 앞선 실행의 수치는 하나도
재계산하지 않았습니다.

[라이브 실측 어댑터](manual/foundry-live.md)는 이 경로를 구현합니다. 실제 Azure Model Router
호출의 토큰 usage로 비용을 계산하고 라이브 호출에만 `measured = true`를 부여합니다. 여러분의
워크로드에서 측정된 절감을 알려면 이 경로를 여러분 테넌트에서 직접 돌리세요.

## 주장 근거 라벨

- **Tier 1 — 벤더 스펙.** 벤더가 공개한 사실입니다. 예: `retry-after-ms` 수용 신호,
  문서화된 캐시 키 임계값, 공개 요율.
- **Tier 2 — 이 프로젝트의 추론/운영 정책.** 프로젝트가 정한 선택입니다. 예: 시드
  pass-rate/`$/resolved` 사전값, 에스컬레이션 임계값, "값 X 이상에서만 앙상블" 규칙.

## 자리표시자 모델과 가격 (투영 트랙)

- **투영 트랙(실험 01–08):** 모델 이름(`mini-fast`, `swift-coder`, `balanced-pro`,
  `deep-reasoner`, `premium-max`)은 모두 일반 자리표시자이며 특정 제품이 아닙니다.
- `samples/pricing/illustrative.yaml`의 요율은 **더미 값**이며 공개된 어떤 가격과도 일치하지
  않습니다. 측정된 숫자가 필요하면 파일을 `your-tenant.yaml`(gitignored)로 복사하고 실제
  요율을 넣으세요.
- **실측 트랙(실험 09·10·11·12·13):** 실제 Azure 배포명과 여러분 테넌트의 실제 요율(gitignored)을
  사용하며 자리표시자가 아닙니다. 공개 아티팩트에는 집계·해시만 남깁니다. 엔드포인트·테넌트
  식별자는 마스킹합니다.

## 어느 절감률이 무엇인가

이 저장소에는 절감률이 셋 나옵니다. 셋은 각각 **다른 arm 쌍**을 나눈 값이라 서로를 대신할 수
없습니다.

- **95.2%** — 실험 12, `router-cost` 대 `direct-premium`.
- **95.8%** — 실험 12, cost-complete인 arm 중 비용이 가장 낮은 것 대 가장 높은 것.
- **94.7%** — 실험 13, 그 실행의 cost-complete인 arm 가운데 `router-cost` 대 `router-quality`.

셋 중 어느 것을 인용하든 **실험 번호와 비교 대상을 함께** 붙여 씁니다.

## 청구 기준

현재 라우터는 미리 계산된 오프라인 신호에서 실행 하나를 고릅니다. 이 신호를 조회하는 일은
모델 호출이 아니므로 원장은 `selected-execution-only` 기준으로 비용을 기록합니다. 미래의 라이브
팬아웃 계층은 모든 패널·심판 호출 비용을 따로 기록해야 합니다.

실측 Model Router 비용은 **기준이 다릅니다.** Azure의 Model Router 과금은 복합적이라 라우터
자신의 input 토큰 마크업에 라우터가 고른 백엔드의 input·output 요율을 더합니다. 실험 11·12·13은
이 두 항목을 합성하는 **`composite-rate-card-v2`** 스키마로 가격을 매기며, 요율 행이 없는
백엔드는 임의 단가로 채우지 않고 unpriced로 봉인합니다(fail-closed). 앞선 실험 09·10의 캡처는
**그 요율 카드보다 먼저** 이뤄져 백엔드 요율만 적용했으므로, 그 실행들의 라우터 금액에는
마크업 항목이 빠져 있고 각 페이지에 불완전으로 표시돼 있습니다.

## 이것은 / 이것이 아닙니다

**이것은** 오프라인 우선·배포 가능한 라우터입니다. 모델 선택 결과를 검사하고 지출을 제한하며
각 결정을 기록하고 라이브 실행으로 결과를 증명합니다.

**이것이 아닌 것:**

- 공식 Foundry 가이드가 아닙니다.
- 측정된 SLA/처리량 모델이 아닙니다.
- 특정 절감 숫자에 대한 약속이 아닙니다.

절감은 전적으로 여러분의 워크로드 구성과 요율에 달려 있습니다. 그래서 증명 단계는
**여러분의 테넌트에서** 실행합니다.

  Azure Foundry 호출이라 여러분의 테넌트에서 실행됩니다.
