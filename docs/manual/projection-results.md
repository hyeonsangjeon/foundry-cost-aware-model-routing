# 오프라인 실험 결과 · 합성 데이터

> **`measured=false` 오프라인 투영.** 이 페이지는 **투영 트랙(실험 01–08)** 의 대표 수치를
> 한곳에 모은 **정본(single source of truth)** 입니다. 모든 값은 합성 워크로드에 대한
> **결정론적 오프라인 계산**이며, 실제 Azure 지출을 측정한 것이 아닙니다. 실측(`measured=true`)
> 결과는 [라우팅 모드 실측 결과 · 03D](03d-results.md)에 따로 있습니다.

!!! abstract "이 페이지의 역할 — 투영 수치의 정본"
    히어로 절감·팬아웃 세금·single-call 격차 같은 투영 수치는 지금 여러 페이지에 흩어져
    반복됩니다. 재런하면 그만큼 여러 곳을 고쳐야 하고, 하나라도 놓치면 페이지 사이에 모순이
    남습니다. 앞으로 이 값들의 **정본은 이 페이지 하나**입니다 — 다른 페이지는 수치를 반복하는
    대신 이 페이지를 **링크**합니다. (기존 페이지에서 중복 수치를 걷어내는 정리는 후속 단계입니다.)

!!! warning "읽는 법 — 투영은 실측이 아니다"
    - **`measured = false`.** 합성 데이터에 대한 오프라인 계산입니다. 측정된 Azure 지출이 아닙니다.
    - **결정론적·재현 가능.** 각 수치는 아래 명령으로 언제든 같은 값이 재생됩니다(유료 호출 0).
    - **방향성 신호.** 설계 논지를 보여주기 위한 값이며, 특정 배포의 성능 보장이 아닙니다.
    - **통과율 = 오프라인 커버리지.** 오프라인 실험·CLI는 통과율을 `coverage` 필드
      (`accepted / counted`)로 출력합니다 — 같은 값입니다. 용어 정의는 [용어집](glossary.md)에 있습니다.

## 한눈에 — 투영 트랙 대표 수치

| 지표 | 값 | 출처 실험 |
| --- | --- | --- |
| 히어로 절감 (비용 인지 vs direct-premium) | **25.5%** ($2.23 → $1.66) | [실험 01 · 히어로](../lab-notebook/01-hero.md) |
| 통과율 (비용 인지 라우팅, 합성 100건) | **100%** (100/100) | [실험 01 · 히어로](../lab-notebook/01-hero.md) |
| 앙상블 팬아웃 세금 | **3.74×** | [실험 05 · 앙상블 팬아웃](../lab-notebook/05-ensemble-fanout.md) |
| single-call 통과율 격차 | **+48%p** (52% → 100%) | [실험 07 · 라우팅 레이어](../lab-notebook/07-model-router.md) |

각 값의 재현 명령은 아래 절에 있습니다. 모든 값은 `labels.measured = false`. 백분율·달러는 표시
정밀도 규약(절감 `%.1f%%`, 비용 `$%.2f`)을 따릅니다.

## 히어로 — 같은 통과율, 더 낮은 비용

합성 워크로드 **100건**을 비용 인지로 라우팅하면 **통과율 100%** 를 유지하면서, 모든 태스크에
프리미엄을 쓰는 direct-premium 기준선 대비 비용을 **$2.23 → $1.66**(**−25.5%**)으로 낮춥니다.

```bash
cost-router hero --json        # total_cost·baseline·delta_pct·coverage
```

- **출처:** [실험 01 · 히어로](../lab-notebook/01-hero.md) · 설정 `experiments/hero.yaml`.

## 앙상블 팬아웃 세금 — 최선을 뽑되 진짜 비용을 치른다

여러 후보를 동시에 부르는 앙상블(팬아웃)은 승자 한 명의 비용 대비 **3.74×** 를 지불합니다.
관찰-후-에스컬레이션은 이 세금을 내지 않고도 같은 목표에 도달합니다(실험 06 참고).

```bash
cost-router experiment run ensemble --json     # tax_ratio·fanout 통계
```

- **출처:** [실험 05 · 앙상블 팬아웃](../lab-notebook/05-ensemble-fanout.md) · 설정 `experiments/ensemble.yaml`.

## single-call 격차 — 한 번 고르기 vs 관찰하고 올리기

`single-call` arm은 프롬프트마다 모델을 **한 번** 고르고 끝냅니다 — 난이도로 한 모델을 미리 고르되
**에스컬레이션이 없어**, 합성 100건에서 **통과율 52%** 에 그칩니다. 관찰-후-에스컬레이션하는
`cost-aware mix` 는 **비슷한 비용**($1.66 vs $1.59)으로 **통과율 100%** 를 채웁니다 — 그 차이
**+48%p**.

```bash
cost-router experiment run single-call --json  # single-call vs mix 커버리지·비용
```

- **출처:** [실험 07 · 라우팅 레이어](../lab-notebook/07-model-router.md) · 설정 `experiments/single-call.yaml`.
- 이 arm은 합성 데이터에 대한 일반 single-call 투영입니다(`measured = false`).
